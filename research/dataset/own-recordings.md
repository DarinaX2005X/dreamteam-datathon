# Собственные постановочные записи для проверки переноса

Эти записи пока **не созданы**. Съёмку выполняют люди команды. Нужны отдельные сцены, которые не участвовали в настройке порогов; исходные видео организаторов нельзя выдавать за собственный пример или публиковать на лендинге.

Снимать без аудио, без реальных банковских данных, с учебными купюрами, пустыми бланками и согласившимися участниками. Лица не нужны для задачи. Минимум два ракурса: высокий диагональный и второй угол с переставленной камерой. Для каждой ситуации сохранять парную корректную запись с теми же предметами и людьми.

| Пара | Записи | Что должен проверить человек перед включением в оценку |
| --- | --- | --- |
| 1 | Кассир считает учебные деньги при клиенте / считает после ухода клиента | Применимость нормы, видимость окна клиента на всём участке, момент начала пересчёта |
| 2 | Кассир остаётся во время операции / уходит при видимом ожидающем клиенте и незавершённой операции | Видны обе стороны рабочего места; уход отличим от наклона за предметом |
| 3 | Рабочий стол с допустимыми предметами / кассир использует личный смартфон | Смартфон различим и не смешивается с рабочим терминалом; принадлежность подтверждена сценарием |
| 4 | Кассир убирает учебные деньги перед уходом / оставляет деньги без присмотра | Различимы деньги и их положение; край кадра и перекрытие не имитируют отсутствие кассира |

Для 8 записей: 4 пары, по 2 пары на каждый новый ракурс, ориентир 15–45 секунд на запись без требования к мгновенной обработке. Это сценарии проверки, не заранее обещанные распознаваемые возможности. Добавлять пример в продукт только после реального локального запуска и ручной сверки результатов.

К каждой записи подготовить `video_id`, SHA256, длительность, `has_violation`, список `label_sec`, подтверждённые `type_code` при наличии нормы, краткий протокол видимого действия, ракурс и имя/псевдоним разметчика. Отдельно записать, что не видно. Нужны точные секунды по исходному файлу, а не по монтажу. Разметчик не должен смотреть ответ модели до своего решения.

Нельзя включать `data/checks/`, пользовательские загрузки и скрытые видео жюри в обучение, калибровку или подбор примера. Если собственная запись используется для настройки, она больше не является независимой проверкой нового ракурса.
