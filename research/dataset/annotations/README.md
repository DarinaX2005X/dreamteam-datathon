# Состояние предметной разметки

В переданном `open.zip` есть только видео и двоичная метка с одним временем на строку. Рамок объектов, сегментации, траекторий и типов событий нет.

**300–600 размеченных кадров сейчас не готовы.** Автоматическая подпись изображения или предложенная детектором рамка не считается ручной разметкой. Для обучения нельзя создать фиктивные COCO JSON либо присвоить видимому человеку/предмету роль без доказательства.

`frame-candidates.csv`, если подготовлен, является только планом извлечения кадров: `requested_sec` не равен подтверждённому PTS извлечённого кадра; `fold` наследуется из SHA-группы источника. Кандидаты не являются аннотациями и не содержат классов.

Для завершения нужны локальный просмотр человеком и разметка 300+ кадров минимум из 30 уникальных источников с сохранением `video_id`, SHA256 и фактического PTS. Инструмент разметки должен работать локально, без внешней передачи банковских кадров. Выход COCO: категории `cash_bundle`, `cash_loose`, `bag`, `phone`, `storage_door_open`, `counter`, `tray`; спорные и неразличимые предметы пропускать с отдельной причиной, а не угадывать. Для дверцы отмечать именно видимое открытое состояние, а не произвольный шкаф.

В каждом COCO image сохранить `source_sha256`, `video_id`, `timestamp_sec`, `fold` и происхождение `human_verified`/`model_proposed`. До ручной проверки `model_proposed` не используется для независимой оценки. Все кадры одного источника остаются в одном фолде, включая Х-4/Х-47 и Х-5/Х-48. Редкий класс честно помечается редким; нельзя дублированием рамок довести его до порога.

Банковские кадры не включаются в публичный репозиторий, README, лендинг и обучающий пакет для третьих лиц. Конкретные ограничения исходного кейса имеют приоритет над разрешением уменьшенных превью из первоначального плана.
