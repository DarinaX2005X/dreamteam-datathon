# Локальное восприятие: проверенные результаты и ограничения

Дата проверки: 17 октября 2026. Это технический отчёт о настоящих запусках, не оценка точности нарушений.

## Проверенное оборудование

Ноутбук: Windows x86_64, Intel Core i7-1260P (12 ядер, 16 потоков), 31.73 GiB RAM,
NVIDIA GeForce RTX 2050 4 GiB, драйвер 581.57. `nvidia-smi` сообщает совместимость драйвера
с CUDA 13.0; установленный PyTorch использует **CUDA 11.8**, это разные значения.
CUDA доступна в PyTorch 2.6.0+cu118. Свободно C: около 102 GiB, D: около 380 GiB на момент
проверки. В момент выбора семантической модели свободная оперативная память составляла
около 9.4 GiB, поэтому нельзя считать все 32 GiB доступными модели.

Целевой NVIDIA Brev L40S 48 GB / 72 GB RAM / 12 CPU / 625 GB SSD ещё не арендован.
Ни время на L40S, ни работа контейнера на таком сервере в этом отчёте не объявлены проверенными.

## Первый реальный сквозной запуск восприятия

Вход: `data/dataset/open/videos/X-1.mov`, SHA256
`8911a9219b9433091824e553a70bb80335f075fd8ac982d2062d2ecf023c16bc`.
H.264, 464×848, 25.933 с, переменные интервалы кадров. Время вычислялось по PTS кадра,
а не через деление номера кадра на условные 30 fps.

Модель: RF-DETR Nano, опубликованная ONNX UINT8 конверсия
`onnx-community/rfdetr_nano-ONNX` revision `eae21cee0687a91bcf9fa071605c48d7705d2d91`.
Файл весов 28,826,010 байт, SHA256
`2981aa0a57781c0f1a5be171c3fded504c38fe8611326bc5e3d0f8a2e9a57085`.
Это открытая конверсия, а не утверждение о побитовой эквивалентности исходному PyTorch checkpoint.

Сохранены настоящие `objects.jsonl`, `tracks.jsonl`, `summary.json` в

По предсказаниям **не вычислялась точность** людей или нарушений: нет ручной покадровой
разметки, пять треков не доказывают наличие пяти разных людей.

Команда, выполненная на этой машине:

```powershell
research/spike/.venv310/Scripts/python.exe research/spike/probe.py --model rfdetr-nano-onnx --video data/dataset/open/videos/X-1.mov --fps 3 --device cpu --offline
```

Линейная оценка для 145 с при тех же 3 fps — около 185 с только inference; целевой бюджет
120 с на CPU этим запуском **не подтверждён**. Скорость на L40S из этой цифры не выводится.
Исходный RF-DETR процессор растягивает изображение до 384×384 и возвращает нормированные
координаты исходного кадра; произвольное добавление letterbox изменило бы модельный препроцессинг.

## Ошибка, найденная реальным запуском

INT8 файл той же конверсии не запускался в ONNX Runtime 1.23.2 CPU: отсутствует реализация
`ConvInteger(10)` для использованной комбинации типов. Этот вариант отклонён.
UINT8 файл прошёл полный запуск на реальном видео. Не подменять его INT8 по сходству имени.
Для CUDA требуется отдельная проверка FP32/FP16 графа и фактически активного CUDAExecutionProvider;
установка `onnxruntime-gpu` сама по себе не подтверждает ускорение.

## Выбор и источники лицензий

| Кандидат | Назначение и ограничения | Статус |
| --- | --- | --- |
| RF-DETR Nano/Small | Люди, телефоны, сумки и остальные классы COCO. COCO не содержит отдельного класса пачки банкнот. Nano/Small имеют Apache-2.0; новые Plus Atto/Femto/Pico/XL с PML не выбираются. | Nano ONNX UINT8 реально проверен; PyTorch/Small ещё не измерены. |
| RT-DETR | Разумная Apache-2.0 альтернатива для COCO, но также не решает деньги и последовательность кассовых действий готовыми весами. | Документация изучена, отдельного локального benchmark нет. |
| RTMPose через rtmlib | Координаты суставов/кистей; движение запястья само по себе не доказывает пересчёт денег. | Код и источник весов подготовлены; реальный запуск ещё ожидается. |
| Grounding DINO Tiny | Открытый словарь для банкнот, лотка, стойки и хранилища. Нужна проверка ложных срабатываний на бумагах и других мелких предметах. | Apache-2.0, официальный revision закреплён; веса загружаются. |
| OWLv2 | Открытый словарь, Apache-2.0; сходный класс возможностей, без доказанной выгоды на этих видео не добавляется второй такой runtime. | Изучена карточка; не скачивался и не измерялся. |
| Florence-2 Base | MIT; локальные диагностические описания отдельных кадров. Не является доказательством порядка действий. | Не используется для нормативного вердикта. |
| InternVL3.5-1B-HF | Apache-2.0; несколько кадров с временными метками, нативный Transformers runtime. Checkpoint 2.12 GB, потенциально помещается на ноутбуке. | Выбран для следующего temporal probe; качество пока не подтверждено. |
| Molmo2-4B | Apache-2.0; нативное видео, pointing и tracking. Языковая основа Qwen3-4B, визуальная SigLIP. Официальный FP32 checkpoint 19.4 GB. | Перспективен для L40S, но текущие свободная RAM и скорость скачивания не дают честно назвать его проверенным. |
| Cosmos-Reason2-2B | NVIDIA Open Model License; 4.88 GB. | HF доступ gated: без согласованного доступа не включается в автономную установку. |

## Граница инженерного решения

Сохраняется конвейер «реальные наблюдения во времени → нормативные условия → эпизод».
Присутствие телефона не доказывает съёмку; деньги в руках не доказывают пересчёт; отсутствие
человека в выборке не доказывает его отсутствие вне кадра. Направление передачи денег требует
сопоставленных actor/recipient и временной последовательности. Возможности, не подтверждённые
реальным extractor, остаются выключенными, соответствующие правила — `not_checkable`.

VLM не должна сочинять `score`: некалиброванная уверенность остаётся `null`. Описание для
пользователя строится из поддержанных структурированных наблюдений и норм, а не свободного
текста модели. Банковские видео, кадры и свободные диагностические описания не передавались
в облачные AI и не открывались через assistant vision. Веб-проверка UI не выполнялась.
