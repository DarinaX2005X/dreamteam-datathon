# Additional data and a 2–3 hour training decision

Research date: 2026-10-17. This note distinguishes the license on the **data** from a repository or downloader license. It excludes noncommercial/research-only data from the usable set and does not treat public benchmark validation/test media as training data.

## Decision

Do **not** bulk-download an action or anomaly benchmark before the first bank-domain measurement. The 32 development videos (24 train, 8 validation) and the ongoing human annotation are far closer to the test distribution than any public candidate below. An adapter is only a parameter-efficient way to update a model; rank 8 versus rank 16 is not the main quality lever. The useful signal comes from the target, sampling, hard negatives, temporal objective, and a label-blind measurement that can reject a worse checkpoint.

Run the prepared 4B rank-8 LoRA as a bounded, measured pilot first. This authorized binary/time pilot does **not** wait for the manual event-type annotation: it uses only the fixed organizer binary and reliable point-time supervision already represented in the training manifest. The manual annotation is an input to a later event-specific ablation, not a prerequisite for this run. The pilot is already aligned with the safe supervision contract: 16 frames at 2 fps; six supervised windows per training source; positive crops contain the organizer point; other windows from a positive video are unknown rather than false negatives; response-only loss; label-blind validation sampling from actual PTS; and no reserved holdout use. The fixed workload is 144 training windows per epoch, 18 optimizer steps per epoch at accumulation 8, 54 optimizer steps over three epochs, plus 66 full-validation windows before training and after each epoch.

The implemented decision gate uses strict paired no-regression on the eight-video validation set. A checkpoint must preserve every source the current reference gets correct and fix at least one previously wrong source. If all video decisions are identical, it may win only by reducing mean timestamp error by at least 0.5 seconds on exactly the same localized positive sources, matching the 2 fps sampling interval. Any invalid generated window or source with no valid output disqualifies the candidate. This is stronger than a scalar balanced-accuracy comparison and prevents trading a false negative for a false positive. With four positive and four negative videos, one changed positive or negative changes balanced accuracy by 12.5 percentage points, so a one-clip gain is permission to continue the bounded pilot, not evidence of a stable population improvement. Inspect the paired video IDs and grounded outputs; do not select on training loss. Preserve the final eight-video holdout until the recipe and threshold are frozen.

If the completed manual annotation adds event types, train those types only from explicit human labels. Do not infer a class from the organizer's binary label or convert a synthetic/open-data endpoint into a bank-law label. `V-OUTSIDER` remains an observation, not an automatic positive violation target. Absence, role, handover, and visibility targets require the corresponding annotated temporal evidence or actual tracks.

Open datasets labeled as shoplifting, crime, or retail anomaly are a poor shortcut even when downloadable. Their camera/scene priors can dominate the tiny bank set, their anomaly definition is not a cash-discipline rule, and many releases have missing or noncommercial media rights. They should not be presented as negatives, positives, or evidence for the six observable rule candidates.

## Two bounded training options

### Option A — recommended now: domain-first measured LoRA

1. Measure the native 4B baseline on all 66 label-blind validation windows and retain per-video predictions, earliest candidate time, and the 4×2 confusion counts. Do not compare against the earlier 1B two-clip anecdote (`TP=0, TN=1, FN=1`); it is a different model and an incomplete sample.
2. Run exactly one prepared LoRA epoch (144 microbatches, 18 optimizer steps), validate once, and measure wall time and peak allocated/reserved VRAM. Continue to epoch 2 or 3 only if the gate above is met and the projected total remains inside the stop budget.
3. After the 32 manual development annotations are complete and audited, add only human-supported auxiliary targets: observable event code, start/end or anchor, and visibility/unclear mask. Use class-balanced sampling by **source video**, retain same-source windows in one group, and choose hard negatives from bank videos that visibly resemble the event (cash present, person at counter, bag present) but do not meet the annotated condition. This is more likely to improve precision than raising LoRA rank.
4. Use domain augmentations that preserve temporal truth: moderate brightness/contrast, JPEG/compression, small scale/crop, and a simulated alternate overhead angle. Apply one transform consistently to every frame in a window. Avoid horizontal reversal where handed layouts matter, frame shuffling for the classification loss, or crops that remove the annotated evidence.

Expected bound: the current eight-video validation can only show large paired changes. Treat “one corrected clip with no regression” as permission for a final development refit, not as a reliable accuracy estimate. Report the exact confusion matrix and localization errors rather than a confident percentage claim.

### Option B — only if Option A fails: frozen visual features + temporal MIL head

Freeze the 4B vision encoder, cache one embedding per sampled frame/window from the 32 development videos, and train a small temporal head (two-layer temporal convolution or transformer, binary window score plus normalized time score). Use video-level max/log-sum-exp MIL for negatives and point-localization loss only where the organizer/manual timestamp is reliable; mask unknown positive windows. Add a temporal-order contrastive auxiliary task made from the same video, and balance sources/classes rather than duplicated windows. This separates temporal discrimination from language generation and should train in minutes after embeddings are cached. It requires implementation and therefore follows, rather than competes with, the ready pilot.

External IPN/CAP/HoloAssist/CaptainCook samples may pretrain the temporal/order encoder, but the bank classification head must be trained and selected only on bank-domain labels. A self-hosted teacher may propose descriptions for human review, within the same compute/time budget; teacher output is weak supervision and cannot establish event type, role, absence, or legal applicability.

## Wall-clock and resource stop rule

Use the actual L40S (46,068 MiB visible), 8 vCPU, 144 GiB RAM and 250 GB disk. Keep the running application available. Train when the model worker is idle, or stop the worker under a controlled maintenance window after confirming that training plus the serving process does not fit measured VRAM; do not guess that concurrent residency is safe.

Budget the run with measured components:

`T_total = T_download + T_decode/cache + T_baseline_validation + epochs × (T_train_epoch + T_validation + T_checkpoint) + reserve`.

The current runner measures the complete first epoch (training, adapter checkpoint and validation). Before starting another epoch it requires room for `max(observed_complete_epoch, baseline_validation) + 60 seconds`. Training and validation loops also stop before the configured deadline with 60 seconds reserved for an adapter-only checkpoint.

The configured wall-clock ceiling is 165 minutes (the CLI rejects values above 180), with a 60-second in-run checkpoint reserve. After epoch 1, stop immediately when there is no paired validation gain. Also stop on non-finite loss, target leakage, changed split fingerprint, incomplete validation, or VRAM pressure that threatens the app. Checkpoints, optimizer state, decoded cache and any optional data must stay below 200 GB combined so at least 50 GB remains for the application, uploads and safe writes. Download/decode/embedding time counts against the same ceiling.

Do not promise throughput before the pilot: frame tiling, dynamic resolution, SDPA, decoding and validation generation dominate differently on this model. The pilot supplies the only defensible extrapolation.

## Minimal download recommendation

For the immediate 2–3 hour decision: **download nothing external**. Measure native 4B and run the authorized binary/time one-epoch gate now; completion of the 32 manual event annotations is not a blocker. If a later auxiliary ablation is already coded, IPN Hand is the only compact video candidate worth staging (4.6 GB, CC BY 4.0). Open Images should be fetched only as a small, per-image-license-verified object subset. Do not fetch CAP's 288 GB archive, HoloAssist's 144.62 GB video set, CaptainCook4D's full recordings, VIRAT, MECCANO, or generic crime/shoplifting data for this run.
