# Айдентика Lado: исходники и правила использования

Каталог содержит реальные ассеты и редактируемые исходники. Решения и их смысл описаны в [`.vibemachina/DESIGN.md`](../.vibemachina/DESIGN.md). Здесь лежат файлы, их размеры и способ пересборки.

Основа: публичный брендбук Forte (https://forte.kz/en/logo, сверено 2026-10-17). Из него взяты четыре фирменных цвета, градиент Dark Magenta → Coral и шрифт Open Sans. Логотип Forte, его форма и словесный знак не используются. Продукт не выдаёт себя за сервис банка.

## Композиции являются образцами, а не скриншотами

`compositions/*.svg` фиксируют иерархию, размеры, отступы и тексты первого экрана и рабочей поверхности. Это не снимки работающего продукта и не обещание точных пикселей: исполнитель строит экран в коде по токенам и DESIGN.md и сверяется с образцом по композиции. Все числа и таймкоды в образцах иллюстративные (данные заданы в `source/build_art.py`), реальные результаты в продукте приходят из API.

Иерархия hero (1440): шапка 72 px; колонка сообщения x 64–620; H1 58/64 ExtraBold; пояснение 18/29; основная кнопка 228×56; вторичная ссылка рядом; оговорка о локальности 14/22. Сцена 672×576 (r28) справа, внутри кадр 640×360 и лента 640×172. Карточка эпизода 348×188 перекрывает левый край сцены и служит мостом между текстом и предметом. Подпись «Иллюстрация…» стоит под сценой справа.

Иерархия рабочей поверхности (1440): панель 64 px; полоса вердикта 64–150; слева сцена 956×782 (видео 800×450 по центру, управление 32–40 px, лента фактов на всю ширину); справа колонка эпизодов 412 px: выбранный эпизод раскрыт, остальные свёрнуты, внизу блок «Без замечаний».

## Пересборка

```bash
pip install fonttools resvg-py pillow
python3 identity/source/build_art.py
OPEN_SANS_TTF=/путь/к/OpenSans[wdth,wght].ttf python3 identity/source/build_identity.py
OPEN_SANS_TTF=/путь/к/OpenSans[wdth,wght].ttf python3 identity/source/build_lado_wordmark.py
```

Шрифт в архив не входит. Вариативный Open Sans (OFL-1.1) лежит в репозитории google/fonts, папка `ofl/opensans`. В продукте шрифт подключается npm-пакетом `@fontsource-variable/open-sans` (или `@fontsource/open-sans`) и раздаётся самим сервисом. Превью рендерятся библиотекой resvg без браузера.

## Правила знака

- Охранное поле вокруг знака не меньше половины ширины ленты (14 единиц сетки 64). В связке отступ между знаком и словом 20 единиц при высоте знака 80.
- Минимальный размер: знак 16 px (используйте `favicon.svg` с толщиной 8), связка 96 px по ширине.
- На тёмной сцене используйте `*-on-stage.svg`: углы и слово светлые, фрагмент сохраняет градиент.
- Не перекрашивать знак вне палитры, не поворачивать, не добавлять тень. Градиент фрагмента (Dark Magenta → Magenta → Coral) является единственным градиентом знака. В одноцветной версии фрагмент заливается цветом знака, лента идёт с прозрачностью 50%.
- Словесный знак Lado набран Open Sans ExtraBold (wght 780) с трекингом −1.2% и переведён в кривые. Не набирать его заново текстом.

## Лицензии и происхождение

Знак, словесный знак (кривые из Open Sans, OFL-1.1 разрешает такое использование), иллюстрации и композиции созданы для проекта. Цвета взяты из открытого брендбука Forte как основа палитры. Сторонних изображений нет.
