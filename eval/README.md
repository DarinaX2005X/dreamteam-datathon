# Воспроизводимая оценка

`labels.csv` — буквальное преобразование разметки организаторов, а не результат модели. Имена `X-1`, `X-2` используют латинскую X; `Х-3` и далее — кириллическую Х. `type_code` пустой, поскольку организаторы типы не разметили и ручной содержательной проверки пока нет.

`source-labels.json` объединяет побайтовые дубликаты, сохраняя их исходные временные метки. Х-4 и Х-47 — один файл с отметками 57 и 68 с; обе сохраняются, их смысл требует проверки. `folds.csv` задаёт 5 фолдов по SHA256 источника: 8 источников в каждом, всего 40. Копии и извлечённые из них кадры должны находиться в одном фолде.

```text
python eval/convert_labels.py data/dataset/open/open_labels.xlsx --videos-dir data/dataset/open/videos
python research/dataset/inventory.py --dataset-dir data/dataset
python eval/make_splits.py
python -m unittest eval.test_convert_labels -v
```

Каждый прогон должен фиксировать версию конвейера, манифест весов, фолд обучения/калибровки и фолд проверки. Нельзя подбирать порог по всему набору и на нём же объявлять независимую точность. Имена роликов/хеши/исходные метки нельзя использовать как признаки модели. Видео жюри и пользовательские загрузки в обучение, подбор порога и оценочный набор не включаются.

Минимальный отчёт содержит число оценённых уникальных видео, TP/FP/TN/FN, точность вердикта, полноту положительных и долю ложных на отрицательных; медиану и p90 ошибки таймкода на действительно сопоставленных событиях. Для отсутствующих предсказаний нельзя молча исключить ошибки обнаружения из отчёта. Совпадение типа нельзя измерить до независимой разметки типов. Фолды в одной сцене не заменяют проверку другого ракурса.

В этой поставке **нет вычисленных метрик модели**. Успешные тесты конвертера подтверждают только схему, целостность данных и отсутствие известных дубликатов между фолдами.
